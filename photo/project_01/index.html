0. 문제 정의

핵심 문제: Photo A의 과거 학습 데이터 800개 고유 샘플로 품질관계를 학습한 뒤, 실제 CD·LER·PASS 정답이 없는 Test A·B 각 200개 공정조건에서 Positive/Negative PR별로 다음에 실행할 가장 정보효율적이고 강건한 DOE의 중심·범위·block·측정계획을 결정해야 합니다.

왜 단순한 최적값 검색이 아닌가

한 조건의 예측 CD가 목표에 가깝더라도 LER·CDU·결함이 나쁘거나 Tool·Field가 달라질 때 붕괴할 수 있습니다. 또한 Holdout에는 정답이 없어 예측점의 실제 성능을 확정할 수 없습니다. 따라서 이 프로젝트의 의사결정 대상은 양산 Recipe가 아니라, 불확실성을 가장 적은 run으로 줄이는 다음 실험입니다.

입력Train 공정조건·실측 품질·PASS와 label 없는 Test A/B 공정조건
핵심 반응LER upper90을 1차 KPI로 두고 CD·CDU·scum·collapse·defect·P(PASS)를 공동 제약으로 사용
의사결정 변수PR Tone별 Dose·Focus·PEB·Develop의 DOE 중심과 low/high, Tool block, Field 측정위치
산출물Tone별 우선 후보, 66-run Resolution IV matrix, 성공·중단·후속 DOE 판정 Gate

제약조건

  • Train과 Test A/B를 섞거나 Holdout 예측값을 pseudo-label로 재학습하지 않습니다.
  • 결측·IQR 이상후보·Lot/Tool 편중과 학습 지원범위를 모델 적용 전에 확인합니다.
  • Positive와 Negative PR은 반응관계가 다르므로 모델·운영선·DOE를 완전히 분리합니다.
  • 파장·NA·pitch·Line/Hole·PR chemistry·깊이 광강도와 실제 사내 Spec은 제공되지 않았습니다.
  • 상관관계나 모델 중요도를 인과효과로 확정하지 않습니다.

문제의 수학적 표현

Choose DOE center, range and blocks to maximize [joint quality margin + Tool/Field robustness + information gain] under [Train support, no leakage, Tone separation, 66-run budget], while minimizing [LER upper risk + prediction uncertainty + candidate-rank instability].

완료 기준

  1. Train-only Lot-OOF가 median/prior 기준모델보다 나은지 검증하고 PI90·calibration을 표시합니다.
  2. Test A/B의 지원범위와 예측 불확실성을 후보 선정에 반영합니다.
  3. CD 단독이 아닌 LER 중심 공동 품질규칙과 Tool·Field 강건성을 통과한 후보를 제시합니다.
  4. 실험 후 곡률·Tool interaction·실패결과에 따라 CCD/RSM, Tool별 DOE 또는 범위 축소로 수정할 수 있어야 합니다.

최종 학습 결론

최적 DOE는 예측점수가 가장 높은 한 점이 아니라, 현재 데이터의 지원범위 안에서 LER 불확실성·CDU·결함·PASS와 Tool·Field 변동을 함께 검증하면서 다음 의사결정을 가장 효율적으로 만드는 실험 설계입니다.

PR Tone은 분리한다Positive와 Negative는 중심조건, 모델, calibration과 공정창 우선순위가 달랐습니다.
CD만으로 결정하지 않는다LER upper90을 핵심 KPI로 두고 CDU·결함·PASS를 공동 제약으로 사용합니다.
강건성이 점수보다 우선이다Tool·Field 공정창과 bootstrap 안정성이 낮으면 점수가 높은 후보도 탈락합니다.
DOE는 순환 과정이다곡률·Tool 차이·실패사례에 따라 CCD/RSM, Tool별 DOE 또는 범위 축소로 수정합니다.

5. 최종적으로 학습한 DOE 선택 방법

Stage Question Evidence
1. Data gate Can the model be applied? Schema, missingness, duplicates, Lot/Tool balance, strict Train support
2. Model gate Which outputs are reliable enough? Lot-OOF vs median/prior baseline, PI90, PASS calibration
3. Candidate gate Does one point satisfy all quality constraints? CD, CDU, LER mean/upper90, scum, collapse, defect, P(PASS)
4. Robustness gate Does it survive Tool and Field changes? Local window, 3 Tools × 5 Fields, bootstrap rank stability
5. DOE gate What experiment reduces uncertainty efficiently? Tone-separated Resolution IV, center repeats, randomization and Tool blocks
6. Update gate What happens after measurement? Curvature→CCD/RSM; Tool interaction→Tool DOE; stable direction→confirmation

Eligible = [|CD−50|<3] ∧ [CDU<3.2] ∧ [LER≤Train Q75] ∧ [LER+PI90≤Train Q90] ∧ [Scum<.25] ∧ [Collapse<.20] ∧ [Defect<.35] ∧ [P(PASS)≥동결 임계값]

최종 설계: Positive/Negative별 4인자 Resolution IV 8조건 + 중심점 3회 × T01/T02/T03 = 66 physical runs. 각 run에서 중심과 네 corner의 5 Field를 측정하고, 실제 실행 순서는 Tool block 안에서 무작위화합니다.

6. 아직 학습하지 못한 것과 다음 검증

실제 테스트 성능A·B label이 없어 외부 R²·MAE·actual PASS/yield를 계산할 수 없습니다.
광학·재료 인과효과파장, NA, pitch, Line/Hole, mask polarity, PR chemistry, 깊이 광강도가 없습니다.
양산 Recipe실제 Spec, 장비 허용범위, 독립 확인실험 없이 확정하지 않습니다.
  1. 양 Tone 중심점 3회를 먼저 측정해 반복성과 PI90 이탈을 확인합니다.
  2. Positive/Negative DOE를 분리 실행하고 주효과·교호작용·Tool·Field 효과를 추정합니다.
  3. 곡률이 있으면 CCD/RSM, Tool interaction이 크면 Tool별 DOE로 수정합니다.
  4. 후속 후보점을 독립 3회 확인하고 실제 Spec을 통과한 뒤에만 양산 검토를 시작합니다.
